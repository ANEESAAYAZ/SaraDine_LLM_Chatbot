# Sara Dine LLM Chatbot 🍛

Sara Dine Chat Assistant is an AI-powered restaurant chatbot built using Python, Streamlit, and Google Gemini.

The chatbot helps customers interact with Sara Dine, a Kerala homemade food restaurant serving customers in Dubai and Sharjah.

Users can ask about the menu and place food orders through a natural language conversation.

## Features

- 🤖 AI-powered conversational chatbot
- 🍛 Provides information about the Sara Dine menu
- 📝 Helps customers place food orders
- 🔢 Handles multiple food items and quantities
- 📍 Collects delivery location
- 🕐 Collects preferred delivery time
- 💰 Calculates order totals using menu prices
- 🚗 Provides delivery information
- 😊 Friendly responses with relevant emojis
- 💬 Maintains conversation context during the chat
